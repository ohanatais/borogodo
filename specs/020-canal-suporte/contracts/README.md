# Contracts — Canal de contato/suporte

**N/A — esta feature não introduz nenhum endpoint de API nem contrato de servidor.**

Não há rota nova, nenhuma chamada ao banco, nenhuma chamada à Anthropic API. A interação de copiar
o e-mail acontece inteiramente no cliente (Clipboard API do navegador). O link do LinkedIn é uma
navegação externa.

Se uma versão futura adicionar um formulário de contato com persistência, o contrato da rota será
definido aqui naquele momento.
